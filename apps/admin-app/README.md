# Goat Assets Dubai - Admin Portal (`admin-app`)

Executive administration dashboard for Goat Assets Dubai Real Estate.

## Features
- **Investor Leads Tracking**: View, filter, and search inbound survey leads (Buying Purpose, Property Type, Budget Allocation, Acquisition Timeline).
- **Portfolio Analytics & KPIs**: Key metrics tracking total leads, High Net Worth allocation, and immediate timeline readiness.
- **Direct Investor Reachout**: Instant WhatsApp chat trigger with pre-filled message, and direct email triggers.
- **Lead Lifecycle Management**: Inline status changes (`New`, `Contacted`, `In Progress`, `Qualified`, `Closed`).
- **Advisor Notes**: Keep confidential client requirement notes.
- **CSV Data Export**: One-click download of all filtered lead records.
- **Manual Lead Creation**: Register offline walk-ins and phone inquiries.

## How to Run
From the root directory or inside `admin-app`:

```bash
cd admin-app
npm install
npm run dev
```

Runs by default on port `3001` (`http://localhost:3001`).
